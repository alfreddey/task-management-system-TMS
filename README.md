## Installation

1. **Prerequisites:**
   - Ensure you have Java installed (JDK 21 recommended).
   - You may also need an IDE such as IntelliJ IDEA (project includes `.iml` files and `.idea` directory).
   - Ensure Maven is installed.

2. **Clone the Repository:**
   ```bash
   git clone https://github.com/alfreddey/task-management-system-TMS.git
   cd task-management-system-TMS
   ```

3. **Install Dependencies:**
   - If using Maven:
     ```bash
     mvn install
     ```

## Run Program

1. **Using an IDE (recommended):**
   - Open the project in IntelliJ IDEA (recommended) or another Java IDE.
   - Use the IDE's run functionality to start the application (typically, the main class is found in `src/`).

2. **Using Command Line:**
   ``` bash
   mvn exec:java -Dexec.mainClass="com.example.MainClass"
   ```
